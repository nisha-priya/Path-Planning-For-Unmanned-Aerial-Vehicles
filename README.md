## Introduction

This repository presents an internship project focused on **Path Planning for Unmanned Aerial Vehicles (UAVs)** in 2D obstacle environments. The project explores algorithmic approaches for finding efficient and collision-free paths between defined start and goal positions.

The study investigates and compares **A\*, Artificial Potential Field (APF), Rapidly-exploring Random Tree (RRT), RRT\*, and Hybrid RRT\*+APF** approaches under different environment sizes and obstacle densities. The resulting paths and performance measures are analyzed to understand the strengths, limitations, and suitability of each approach for UAV path planning.

The repository provides the **project report and experimental results**, including path-planning outputs and performance comparisons obtained during the internship.
